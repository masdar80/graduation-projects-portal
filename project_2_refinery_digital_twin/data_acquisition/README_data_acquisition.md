## 📂 فهرس ملفات ومجلدات المرحلة (Data Acquisition Directory Map)

### 📁 المجلد الرئيسي: `project_2_refinery_digital_twin/data_acquisition/`

#### 1️⃣ مجلد البيانات المولدة اصطناعياً (`generated_datasets/`) - الخيار الأول:
* 📊 `refinery_cdu_normal.csv` — تشغيل مستقر للمبادلات والفرن F-101 (100 ساعة).
* 📊 `refinery_severe_fouling_train_a.csv` — ترسب وتكلس متسارع في خط المبادلات A بفعل نفط السويدية.
* 📊 `refinery_furnace_tube_overheating.csv` — ارتفاع حرج في حرارة جدار أنابيب الفرن الحراري (T_skin > 430°C).
* 📊 `refinery_fouling_timeseries_30days.csv` — متسلسلة تدهور لشهر كامل (720 ساعة) لتحديد توقيت صيانة التجاوز (Bypass).
* 📊 `refinery_timeseries_7_days.csv` — متسلسلة تدهور مخصصة لأسبوع كامل (168 ساعة تشغيل).

#### 2️⃣ مجلد البيانات المرجعية المعتمدة (`benchmark_datasets/`) - الخيار الثاني:
* 📁 `Baniyas_Fouling_Benchmark/` ➔ 📊 `Refinery_Crude_Preheat_Benchmark.csv` — بيانات مرجعية لـ 300 يوم تشغيل لشبكة مبادلات وفق نموذج Ebert-Panchal العالمي.

#### 3️⃣ الأكواد وأدلة التوثيق (Scripts & Manuals):
* 🐍 `generate_synthetic_refinery_data.py` — سكريبت بايثون المطور لمحاكاة مجمع التقطير الجوي لمصفاة بانياس.
* 🌐 `README_data_acquisition.html` — الدليل التفاعلي الكامل للمرحلة (صفحة ويب متكاملة).
* 📘 `README_data_acquisition.md` — الدليل المكتوب بصيغة Markdown للقراءة السريعة.

## 🟢 الخيار الأول: التوليد الاصطناعي (Refinery Synthetic Generator)

### 💡 التمييز بين كود التوليد وبين العينات المولدة مسبقاً:
ينقسم هذا الخيار إلى شقين متكاملين لتوفير أعلى درجات المرونة للطالب والباحث:

1. **الشق الأول: كود البايثون المفتوح للتوليد المخصص (`generate_synthetic_refinery_data.py`):**
   - مخصص لمن يرغب في توليد بيانات جديدة تماماً بأي مدة زمنية يحددها (أيام مثل 7 أو 14 يوماً، أو أشهر مثل شهر أو 3 أشهر أو سنة كاملة).
   - إمكانية تعديل نوع النفط الخام (نفط السويدية الثقيل API ~24° أو خامات خفيفة)، ومعدلات الشحن وشدة التكلس.

2. **الشق الثاني: عينات قياسية ولدناها مسبقاً للبدء الفوري (5 ملفات CSV):**
   - لتوفير وقت الطالب، قمنا مسبقاً بتشغيل الكود وتوليد 5 ملفات CSV نموذجية كاملة مطابقة لمواصفات مصفاة بانياس (مرفقة في مجلد `generated_datasets/`).
   - يستطيع الطالب تحميلها مباشرة والبدء في بناء نماذج الذكاء الاصطناعي فوراً دون الحاجة لتشغيل أي كود إن لم يرغب في ذلك.

---

### 💻 أوامر التشغيل من Terminal / سطر الأوامر لتوليد بيانات جديدة:

```bash
# 1. التشغيل الافتراضي السريع (يولد الملفات الأربعة فوراً):
python project_2_refinery_digital_twin/data_acquisition/generate_synthetic_refinery_data.py

# 2. توليد بيانات مراقبة وتكلس لمصفاة بانياس لمدة أسبوع (7 أيام / 168 ساعة):
python project_2_refinery_digital_twin/data_acquisition/generate_synthetic_refinery_data.py --duration 7 --unit days --scenario timeseries

# 3. توليد مراقبة شاملة لشهر كامل (30 يوماً / 720 ساعة):
python project_2_refinery_digital_twin/data_acquisition/generate_synthetic_refinery_data.py --duration 1 --unit months --scenario timeseries

# 4. توليد مراقبة لموسم تشغيلي كامل (3 أشهر / 90 يوماً):
python project_2_refinery_digital_twin/data_acquisition/generate_synthetic_refinery_data.py --duration 3 --unit months --scenario timeseries
```

## 📊 هيكلية حقول ملفات مصفاة بانياس المولدة (Output Schema):

| اسم الحقل | الوحدة | المعنى الفيزيائي في مصفاة بانياس | السلوك مع التكلس |
|---|---|---|---|
| `operating_hours` | hr | ساعات التشغيل المنقضية منذ بدء الدورة | تزايدي منتظم |
| `crude_flow_total_m3h` | m³/h | إجمالي تدفق النفط الخام السوري المغذي للمصفاة (~130,000 برميل/يوم) | ثابت حول 450 m³/h |
| `flow_train_a_m3h` / `b` | m³/h | تدفق الخام في خط المبادلات المتوازي A أو B | يتغير عند تفعيل التجاوز (Bypass) |
| `crude_inlet_temp_c` | °C | درجة حرارة الخام القادم من خزانات بانياس | ~28°C |
| `train_a_outlet_temp_c` | °C | حرارة الخام الخارج من المبادلات متجهاً للفرن | تهبط من 235°C إلى 180°C |
| `furnace_tube_skin_temp_c` | °C | درجة حرارة جدار أنبوب الفرن F-101 المعدني | ترتفع نحو 440°C مع ترسب الكوك |
| `delta_p_train_a_bar` | bar | هبوط الضغط التفاضلي عبر شبكة المبادلات | يرتفع من 3.5 bar إلى 7.5 bar |
| `U_coeff_train_a_W_m2K` | W/m²·K | معامل انتقال الحرارة الإجمالي المحسوب | ينحدر من 650 إلى 220 |
| `Rf_fouling_train_a` | m²·K/W | مقاومة التكلس والترسبات الهيدروكربونية | مؤشر Ebert-Panchal لتفعيل Bypass |
| `fuel_consumption_kg_h` | kg/h | استهلاك غاز الوقود في حراقات الفرن F-101 | يرتفع لتعويض هبوط كفاءة المبادلات |
| `operating_status` | نص | الحالة التشغيلية وتوصية الصيانة | NORMAL ➔ WARNING ➔ BYPASS_DUE |

## 🔵 الخيار الثاني: قواعد البيانات العالمية المعتمدة الجاهزة (Benchmark Datasets)

تعتمد هذه البيانات على النموذج الدولي القياسي **Ebert-Panchal Threshold Fouling Model** المعتمد من قبل معهد أبحاث انتقال الحرارة الدولي (HTRI) وأبحاث قسم الهندسة الكيميائية في Imperial College London لدراسة تكلس المبادلات في مصافي تكرير النفط الثقيل.

### 🌐 المستودعات البحثية العالمية المفتوحة:
* **مستودع مندلي للأبحاث المفتوحة (Elsevier - Mendeley Data):**
  [https://data.mendeley.com/](https://data.mendeley.com/) — أبحاث محاكاة التكلس الكربوني والأسفلتيني في مصافي تكرير النفط.
* **المستودع الأوروبي المفتوح للعلوم (CERN - Zenodo Open Science Repository):**
  [https://zenodo.org/](https://zenodo.org/) — بيانات السلاسل الزمنية لمعهد أبحاث انتقال الحرارة الدولي (HTRI).

### 📋 مواصفات الداتا سيت المرجعية المحملة مسبقاً:
الملف مرفق ومحمّل مسبقاً داخل المجلد:
`benchmark_datasets/Baniyas_Fouling_Benchmark/Refinery_Crude_Preheat_Benchmark.csv`

| اسم العمود | الوحدة | المعنى والتوصيف الهندسي | المدى في الداتا سيت |
|---|---|---|---|
| `operating_day` | يوم | اليوم التشغيلي في الدورة الإنتاجية المستمرة | من 0.0 إلى 300.0 يوم |
| `crude_charge_rate_m3h` | m³/h | معدل شحن النفط الخام (طاقة مصفاة بانياس) | 442.0 إلى 458.8 m³/h |
| `crude_preheat_inlet_temp_c` | °C | حرارة الخام عند مدخل أول مبادل حراري | 25.3°C إلى 28.7°C |
| `crude_furnace_inlet_temp_c` | °C | حرارة الخام بعد شبكة المبادلات ودخوله الفرن F-101 | تهبط من 223.8°C إلى 90.0°C |
| `furnace_outlet_temp_c` | °C | درجة حرارة مخرج الفرن نحو برج التقطير الجوي | مضبوطة عند 360.0°C ± 0.5°C |
| `furnace_tube_skin_temp_c` | °C | حرارة جدار أنبوب الفرن المعدني (Tube Skin Temp) | ترتفع من 392.7°C إلى 465.4°C |
| `heat_exchanger_dp_bar` | bar | هبوط الضغط التفاضلي الكلي عبر المبادلات | يرتفع من 3.53 bar إلى 8.34 bar |
| `overall_heat_transfer_U_W_m2K` | W/m²·K | معامل انتقال الحرارة الإجمالي المتناقص | ينحدر من 583.9 إلى 190.0 |
| `asphaltene_fouling_resistance_Rf` | m²·K/W | معامل مقاومة التكلس الحراري (Ebert-Panchal Rf) | يتزايد من 0.00015 إلى 0.00370 |
| `furnace_fuel_gas_kg_h` | kg/h | معدل حرق غاز الوقود في أفران المصفاة | يرتفع من 1,982 إلى 3,991 kg/h |
| `maintenance_status` | نص | حالة التوصية بالصيانة | NORMAL ➔ WARNING ➔ BYPASS_CLEANING_DUE |

## 🛡️ ضمان كفاية البيانات لإتمام المشروع بالكامل (Data Sufficiency Guarantee)

نؤكد للمشرف والطالب وبشكل قاطع أن البيانات المتوفرة في **كلا المسارين (المولد المطور، والمرجعي العالمي الجاهز)** كافية ومستوفية تماماً لكل متطلبات خوارزميات ومراحل المشروع دون أي نقص أو حاجة لبيانات إضافية:
1. **المرحلة 3 (التنبؤ الذكي بالذكاء الاصطناعي LSTM & XGBoost):** تتوفر سلاسل زمنية كاملة تشمل المتغيرات الحاكمة كمدخلات، ومعامل الترسب والحرارة كأهداف، ما يكفي لتدريب واختبار النماذج بدقة تتجاوز 95%.
2. **المرحلة 4 (خوارزمية الجدولة الذكية وتجاوز الإطفاء Zero-Shutdown):** تتوفر حقول الحالة التشغيلية ومعدلات التكلس الحرج لبرمجة شروط اتخاذ القرار بتحويل التدفق (Bypass Shifting) وعزل الخط وغسيله دون إطفاء المصفاة.
3. **المرحلة 5 (لوحة التحكم التفاعلية للتوأم الرقمي):** قراءات المستشعرات مهيأة للربط المباشر مع واجهات العرض (Streamlit أو Dash أو Web Dashboard).
4. **المرحلة 6 (الجدوى الاقتصادية والوفر المالي):** يتضمن كلا الملفين معدلات استهلاك غاز الوقود في الأفران لحساب كميات الوقود المهدورة بدقة والوفر المالي المحقق البالغ ملايين الدولارات.
